# Source Icon Logos

Place neutral-base (white on transparent) PNG logos here for each session type.
The icon generator tints these at session launch using color theory.

Expected files:
- `claude-logo.png` — Claude logo, white on transparent, 128×128 or larger
- `gemini-logo.png` — Gemini logo, white on transparent, 128×128 or larger
- `shell-logo.png` — Terminal/shell icon, white on transparent
- `chrome-logo.png` — Chrome icon, white on transparent
- `caffeinate-logo.png` — Caffeinate icon, white on transparent
- `ssh-logo.png` — SSH/network icon, white on transparent

If a file is missing, the generator falls back to a simple white rounded-square
placeholder icon with the correct tint applied.
