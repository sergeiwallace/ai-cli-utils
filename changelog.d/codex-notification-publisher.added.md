`ai cx` can call an optional notification publisher (`[codex.publisher] command`) so another tool can deliver notices into a supervised Codex session. With a publisher that accepts the session, Codex runs on its own app-server at the socket the publisher names, and the launcher enrolls, refreshes and finishes the session's thread through the publisher's phases. Any refusal, timeout or unreadable answer launches Codex as before and prints one notice. Bare launches and Windows never call it.
