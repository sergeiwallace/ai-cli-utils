- Every way an `ai c` tmux session ends returns the terminal to the shell that ran `ai c`, with the terminal pane left open. A restart policy of `never`, `[session] auto_restart = false` and a failed remote launch now end the session instead of leaving a shell in the tmux pane; a session whose supervisor dies is ended by tmux for an attached terminal. Run from inside tmux, `ai c` (including its continuation after a reinstall) switches that terminal's tmux client to the new session instead of refusing, and the client returns to its own session when the new one ends.
