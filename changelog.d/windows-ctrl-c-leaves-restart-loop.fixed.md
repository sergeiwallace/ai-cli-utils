- On Windows (Git Bash, psmux), pressing Ctrl+C repeatedly in an `ai c` session now ends Claude Code and then the auto-restart loop, as on Linux and macOS. Two things kept the pane from closing. The wrapper ran the agent as a background job and waited for it, and under Git Bash that wait never returned once Ctrl+C presses arrived while the agent was exiting, so a recorded stop was never acted on. And the wrapper's "Ctrl+C again within 3s" rule could not be met there: each press waited behind a slow native helper, so presses arrived seconds apart and each counted as a first press again. The agent now runs as the wrapper's foreground command on Windows, and any Ctrl+C that reaches the wrapper stops the session. A single Ctrl+C inside Claude Code is still a key Claude Code reads and reaches only it. Sessions already running keep their loaded script until they are relaunched, and `ai --restart-session` still accepts them.
