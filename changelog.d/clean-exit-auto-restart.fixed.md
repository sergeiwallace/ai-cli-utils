- Claude Code restarts again after `/exit`, Ctrl+D or its own double Ctrl+C in an `ai c` tmux session, as `[session] auto_restart` documents. Claude Code returns 0 for all three, and the wrapper had been treating every exit with status 0 as a request to end the session, so after one of them it printed "Auto-restart stopped" and closed. A clean exit after a healthy run now restarts the agent after a three-second window, and a Ctrl+C in that window ends the session. A clean exit in the first three seconds still ends it. Sessions already running keep their loaded script until they are relaunched, and `ai --restart-session` still accepts them.
