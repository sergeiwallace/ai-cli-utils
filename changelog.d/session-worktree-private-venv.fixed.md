- A new session worktree of a uv-locked project gets its own `.venv`. The launcher runs `uv sync --frozen` inside the worktree before returning it. Before, `.venv` was linked to the main checkout, so every session of a project shared one environment, and a `uv sync` in any of them rewrote the editable install the others imported. A missing `uv` or a failed sync stops the launch with the reason. Set `[worktree] venv = "link"` to keep the shared link, and `[worktree] venv_sync_timeout_seconds` (default 900) to bound the first sync. A reused worktree's existing `.venv` is left alone, and a project without a `uv.lock` keeps the link.
