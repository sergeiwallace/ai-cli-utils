- A fetch of a shared name registry that times out or loses its connection is retried under `[retry.registry_fetch]`, each attempt with a longer timeout. A credential the remote refuses is reported once, as "authentication refused", with git's own last line and the credential helper's first, rather than the helper's whole restore walkthrough. `[session_names] registry_fetch_timeout_seconds` is removed: set `[retry.registry_fetch] timeout_seconds` instead.
