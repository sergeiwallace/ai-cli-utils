`-A/--split` on every session launch (`ai c`, `ai g`, `ai p`, `ai cx`, `ai agy`) starts the session detached and, on macOS inside iTerm2, attaches it in a vertical split of the launching pane, then selects the launching pane again so the focus stays there. Outside iTerm2, or when the split fails, the launch warns with the `ai attach` command and the session keeps running detached. It cannot be combined with `-R/--remote` or `-b/--bare`. A launch that the config or a missing tmux turns bare warns that nothing is split.
