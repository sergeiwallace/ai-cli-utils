- A session the iTerm2 restore sweep proves dead (its tmux session is gone) now also reads exited through its run state. Before, the sweep wrote only `exit` and `ended_at`, and every reader (`ai sessions list`, the migration preflight, the launch guard) reads the run state first, so the dead session kept reading running. An exit a hook reports with `ai iterm2 sessions -x` stays evidence and does not change the run state.
