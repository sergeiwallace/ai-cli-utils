# Decision records

One file per decision, named `NNNN-title.md` and numbered in order. A record names the
files it governs, the decision, the reason, and the rejected alternative where there is
one. Decision records replace code comments that explained a choice; see
`docs/procedures/comment-ratchet.md`.

Records about files that project-template manages are in [template/](template/). Edit
those in project-template, not here: copier delivers them with each update.
