# Plans

Implementation plans with tasks, batches, and gates.

## What belongs here
- Implementation plans for features and fixes (task breakdowns, options, pros/cons)
- Sprint plans and batch execution guides
- Migration plans with step-by-step instructions
- Must follow template: options, pros/cons, recommendations

## Archive
Completed or superseded plans live in `archive/`. Use `git mv` to move them; set `status: archived` in frontmatter.

## What does NOT belong here
- High-level architecture or design rationale -> use `designs/` instead
- Prioritized task lists and epics -> use `roadmap/` instead
- External research informing the plan -> use `research/` instead
- Rough unstructured ideas -> use `brainstorming/` instead
