# Archive

Deprecated or superseded docs preserved for reference.

## What belongs here
- Docs with `status: archived` or `status: superseded` in frontmatter
- Old plans, designs, or research that have been replaced by newer versions
- Historical artifacts no longer actively referenced

## What does NOT belong here
- Active docs that are just old -> keep them in their original directory
- Scratch/throwaway content -> use `scratch/` instead
- Completed docs that are still referenced -> keep in place, set `status: completed`
