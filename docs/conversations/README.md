# Conversations

Exported Claude Code session conversations (auto-generated).

## What belongs here
- Auto-exported CC session transcripts via `python3 scripts/export_conversations.py`
- Named by date and session identifier

## What does NOT belong here
- Handoff context for cross-session delegation -> use `handoffs/` instead
- Journal reflections on session work -> use `journal/` instead
- Research findings discussed in a session -> use `research/` instead
