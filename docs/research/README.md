# Research

External investigation with citations and sources.

## What belongs here
- Research reports with specific citations and a Sources/References section
- Comparison studies, best-practice surveys, deep dives
- Must include `## Appendix: Research Prompt` with registry ID, model, date, full prompt
- One doc per research run; use synthesis docs to combine multi-round findings

## What does NOT belong here
- Design decisions derived from research -> use `designs/` instead
- Rough ideas or brainstorms -> use `brainstorming/` instead
- Learning notes without external citations -> use `learn/` instead
- Tradeoff analyses from discussions -> use `analysis/` instead
