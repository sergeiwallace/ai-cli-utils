# Documentation Index

## Directory Guide

| Directory | Purpose |
|-----------|---------|
| `analysis/` | Tradeoff analyses, strategy evaluations from discussions |
| `archive/` | Deprecated or superseded docs |
| `bugs/` | Bug investigations, reproduction steps, root cause analysis |
| `conversations/` | Exported CC session conversations (via `scripts/export_conversations.py`) |
| `designs/` | Sub-system architecture blueprints |
| `handoffs/` | Cross-session delegation context and startup docs |
| `plans/` | Implementation plans with tasks, batches, gates |
| `procedures/` | Session config how-to docs (referenced by CLAUDE.md) |
| `research/` | External investigation with citations and sources |
| `roadmap/` | Prioritized task lists, epics, milestones |
| `test/` | Test documentation, coverage reports |
| `guides/` | User-facing setup guides for optional features (NATS, etc.) |
| `tools/` | Tool docs, CLI references, integration guides |

**Rules:** When creating a new subdirectory, add a README.md AND update this table. Each subdirectory has its own README.md with detailed guidelines.
