# Documentation

This directory contains project documentation organized by purpose. Use the documentation search system to find material by topic; this guide explains where new or related documentation belongs.

## Directory guide

### analysis

Technical evaluations, tradeoff reasoning, and retrospective analysis that may inform more than one area of the project.

### archive

Superseded, deprecated, or abandoned documentation retained for historical reference.

### audits

Structured reviews of code, documentation, plans, or systems, including findings and verification checklists.

### bugs

Bug investigations that record symptoms, root causes, fixes, and follow-up status.

### conversations

Exported development-session transcripts retained as a record of discussions and decisions.

### designs

Architecture and subsystem design material, including design rationale and implementation constraints.

### guides

User-facing setup and how-to guidance for optional features and integrations.

### handoffs

Context and startup material for transferring work between development sessions.

### plans

Implementation, migration, and execution plans with tasks, sequencing, and gates.

### procedures

Repeatable operational and development workflows, including detailed step-by-step instructions.

### reference

Reference material such as configuration examples and technical specifications used while working with the project.

### research

External investigations, comparisons, and deep dives supported by citations and source material.

### roadmap

Prioritized work, milestones, and longer-term planning information.

### test

User-acceptance testing records, coverage reports, and other test documentation.

### tools

Documentation for developer tools and command-line utilities used with the project.
