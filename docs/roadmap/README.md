# Roadmap

Prioritized task lists, epics, and milestones.

## What belongs here
- Master roadmap and project-specific roadmaps
- Era-based priority planning
- Migration tracking with completion status
- Tasks tagged P0-P3, grouped by priority

## What does NOT belong here
- Detailed implementation steps for a single feature -> use `plans/` instead
- Long-term vision and philosophy -> use `vision/` instead
- Per-project status and coordination -> use `projects/` instead
