# Bugs

Bug investigations, reproduction steps, and root cause analysis.

## What belongs here
- Bug investigation docs with reproduction steps
- Root cause analysis write-ups
- Workaround documentation for known issues
- Follow the `TEMPLATE.md` in this directory

## What does NOT belong here
- Bug fix implementation plans -> use `plans/` instead
- Test coverage docs -> use `test/` instead
- Infrastructure issues -> use `infra/` instead
